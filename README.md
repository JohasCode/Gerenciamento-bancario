# Gerenciamento bancário
## Sobre o projeto
Uma pequena aplicação de gerenciamento bancário que criei em Java utiizando o software IDE [NetBeans](https://netbeans.apache.org/front/main/download/) com [Java JDK](https://www.oracle.com/br/java/technologies/downloads/) instalado e os principais conceitos do paradigma de Orientação a Objetos.

## Funcionalidades
Ele possibilita que o usuário informe seu nome, sobrenome e CPF. Além
disso, a aplicação possibilita ao usuário consultar saldo, realizar depósitos e saques.
Esses procedimentos se repetem até que o usuário escolha encerrar o uso da aplicação.

## Aprendizados e desafios
Foi a minha primeira vez utilizando a linguagem Java e achei uma experiência divertida, essa
atividade me permitiu ver na prática como a linguagem funciona, além de como o IDE
NetBeans pode ser versátil ao ver a quantidade de recursos que ele apresenta.
Confesso que particularmente não fui muito fã da linguagem, depende de pessoa pra pessoa,
mas é sempre muito gratificante ver algo que você programou funcionando, e pra mim,
aprender coisas novas também.
